# Помодоро-таймер

Таймер по технике «Помодоро» в одном HTML-файле — без установки, сборки и зависимостей.

## Запуск

Откройте `index.html` в любом современном браузере.

## Возможности

- Три режима: **Фокус** (25 мин), **Перерыв** (5 мин) и **Длинный** перерыв (15 мин). Длительность меняется в разделе «Настройки».
- После каждого четвёртого помидора автоматически начинается длинный перерыв.
- Счётчик помидоров за сегодня.
- Список задач: задача, отмеченная кружком, получает помидоры за каждую завершённую сессию фокуса.
- Звуковой сигнал и уведомление браузера по окончании сессии.
- Светлая и тёмная тема — по настройкам системы.
- Задачи, статистика и настройки сохраняются в `localStorage` браузера.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Пробел  | Старт / пауза |
| R       | Сбросить текущую сессию |
| S       | Пропустить (без начисления помидора) |
